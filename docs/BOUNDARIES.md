# 公开数据与私有运行时边界

## 本包的职责

本包是一个单脸展示页：让使用者看到流明脸部参考、语义类别、公开表演片段和基础播放状态。它用于说明模型套组包含什么，不是角色制作工具。

## 收录的资源

- 流明独立脸部几何、必要绑定、静态展示姿态和脸部纹理。
- 语义 ONNX 权重、分词器、类别与上下文目录。
- 97 段公开表演曲线、166 维原始控制列、片段边界与标签。
- 单脸网页展示代码和用户自配置的 LLM / TTS 代理。
- 独立实现的基础相机视线跟随、头部微动、普通交叉淡入淡出与自动回自然播放。

## 不提供的工具

- 形态键滑条、逐通道校准和动作编辑器。
- 自定义角色上传、模型替换、拓扑匹配和自动适配。
- Blender 插件、形态键转移、权重生成和导出器。

用户在 Blender 中载入资源仓库提供的 `lumen-reference-face.blend` 和自己的角色，通过 MCP 让 AI 分析并类比制作同名 shape keys，再生成双模型联动面板，人工逐项修正。面板由使用者的 AI 自行编写，不是本包内置工具。这个适配过程属于用户的建模工作，不属于本包的网页运行时。具体流程见 [Blender＋MCP 适配教程](ADAPTING_YOUR_MODEL.md)。

## 未收录的实现及参数

- 原工程脚本、浏览器宣传页运行时和后端会话运行时。
- 主项目的面捕映射、眼球软限位、闭眼联动和视线调度实现与参数。
- 主项目的程序化眨眼、微动、自然放松生成和导演事件调度。
- 动作图重组、跳转门限、惯性过渡和按通道衰减。
- 嘴部 baseline、主口型/overlay 分层和收口策略。
- 头发动力学、碰撞配置和 Unity 肌肉到骨骼求解表。
- 私有服务地址、密钥、角色提示词、宣传拍摄快捷键。

原清单中的行为配置不随曲线分发；曲线只按白名单导出公开片段数据和标签。

## 参考页面的行为

网页按片段时间读取相邻曲线帧，并使用普通线性插值，把可匹配的形态键值写入唯一的流明脸部。切换表演时使用 0.4 秒的普通交叉淡入淡出，结束后回到自然片段并循环；语音播放结束也会触发回自然。相机视线跟随独立从双眼中点计算共同方向，采用保守角度限位和共享四元数插值，将相同旋转同步应用到双眼；头部微动采用简单正弦变化。它不会从历史帧预测动作，也不生成或同步口型。

参考提示词公开说明虚拟角色身份和当前可用标签。额外的左右单眉标签由网页直接控制 `eyebrow_up_R/L`，用固定幅度和普通平滑曲线回落，保留另一侧眉毛的基线。这是独立实现的基础规则，未调用 ONNX 推理、未训练新权重，也未移植主项目的部位动作调度或私有角色提示词。

本地语义入口执行普通 ONNX 类别选择。网页优先选择相同类别、相同上下文的固定片段，没有上下文匹配时选择该类别的第一个片段。它不包含主项目的低置信度门控、随机表演策略或导演规则。

## 表述约定

可以称为“中文语义驱动的表演选择与单脸参考预览”。

不能把这个展示页称为主项目完整运行时、下一帧预测器或自动角色适配器，也不能把主项目的视线、口型或过渡效果描述为本包开箱即可复现的能力。
